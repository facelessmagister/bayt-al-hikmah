## WHILE-READING (Read the Text)

### Part 1: Why Python?

There are hundreds of programming languages in the world. So why do so many teachers recommend Python as a first language?

The answer is simple: Python is easy to read. Python's syntax — the rules for writing the code — looks a lot like plain English. Compare these two programs that do the same thing:

In Java, you write: `System.out.println("Hello!");`
In Python, you write: `print("Hello!")`

The Python version is shorter and easier to understand. You do not need to know a lot of complicated rules just to write your first program. This is why Python is used in schools all over the world.

Python was created in 1991 by a programmer named Guido van Rossum. He wanted a language that was powerful but also simple and fun. He named it after his favourite comedy show, not after the snake!

### Part 2: Your First Program and Data Types

The first program most people write in Python is very simple. It has just one line:

`print("Hello, world!")`

When you run this program, the computer shows the words "Hello, world!" on the screen. The word `print` is a function — a reusable block of code that does a specific job. The function `print()` shows text on the screen.

But Python can work with different kinds of data. The two most common types are strings and integers.

A string is text data. It is a sequence of characters wrapped in quotation marks. "Hello, world!" is a string. "I love pizza" is also a string. Even "123" can be a string if you put it in quotes.

An integer is a whole number. The number 42 is an integer. The number 0 is an integer. But 3.5 is not an integer — it has a decimal point. In Python, numbers with decimal points are called floats.

Python also has lists. A list is an ordered collection of items stored together, just like a shopping list. You can create a list of your favourite colours: `colours = ["red", "blue", "green"]`. Then you can add to it, remove from it, or change items in it.

### Part 3: Making Your Code Do More

Once you can write simple programs, you can start making them smarter. Python has several tools that help you do this.

A function lets you reuse code. Instead of writing the same instructions again and again, you put them inside a function and give it a name. Then you just call the function whenever you need it. For example, you could write a function called `greet()` that says hello. Every time you call `greet()`, the program says hello — without rewriting all the code.

A comment is a note in your code that the computer ignores. In Python, comments start with the `#` symbol. Comments help you remember what your code does. They are very useful when you come back to a program after a few weeks and have forgotten what you wrote.

A library is a collection of pre-written code that you can use in your programs. Instead of writing everything from scratch, you can import a library and use its functions. For example, the `random` library lets you generate random numbers. This is useful for making games where you need dice rolls or random surprises.

With these tools, you can build real projects. A 12-year-old can write a guessing game, a maths quiz, or a program that tells jokes. Some learners even build simple games using a library called Pygame.

### Part 4: Real-World Python

Python is not just for beginners. It is one of the most popular languages in the real world. Scientists use Python to analyse data. Companies like Google, Netflix, and Instagram use Python to run parts of their systems. People use Python to build websites, create games, and even train artificial intelligence models.

One of the reasons Python is so popular is its community. Millions of programmers share their code online. If you have a problem, someone has probably already solved it and posted the answer. You can find free tutorials, videos, and projects on websites like code.org, Khan Academy, and the official Python website.

Learning Python at 12 is a smart choice. You are old enough to understand the ideas and young enough to have plenty of time to practise. You do not need a powerful computer — Python runs on almost any laptop. You can even try it in your web browser without installing anything.

The most important thing is to start small and keep going. Write one line. Then write two. Fix the bugs. Try again. Before long, you will be building programs that you never thought you could make.
