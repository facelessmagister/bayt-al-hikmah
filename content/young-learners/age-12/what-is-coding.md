## WHILE-READING (Read the Text)

### Part 1: What Is Coding?

Every time you play a video game, send a message, or watch a video online, you are using software. But how does software work? The answer is coding.

Coding means writing instructions that a computer can understand. Computers cannot think for themselves. They do not know what you want unless you tell them — step by step, in a language they understand. These instructions are called code, and the people who write code are called programmers.

A computer is like a very fast but very literal worker. It will do exactly what you tell it to do — nothing more, nothing less. If you tell a robot to walk forward, it will keep walking until it hits a wall. You have to be very careful and very clear when you write code.

### Part 2: Algorithms — Recipes for Computers

Before you write code, you need a plan. This plan is called an algorithm. An algorithm is a step-by-step set of instructions for solving a problem.

Think about making a sandwich. The algorithm might be: 1) Get two slices of bread. 2) Spread butter on the bread. 3) Add cheese. 4) Put the slices together. If you follow these steps in order, you get a sandwich.

But what if you put the cheese on first, then the butter, then the bread? The sandwich would not work. The order of the steps matters. This is one of the most important ideas in coding: the order of your instructions changes the result.

Programmers write algorithms before they write code. They plan each step carefully. Then they translate the algorithm into a programming language that the computer can read.

### Part 3: Variables, Loops, and Conditions

Once you understand algorithms, you can start using the building blocks of code. Three of the most important building blocks are variables, loops, and conditions.

A variable is a container that stores information. Think of it like a box with a label on it. You can put something inside the box, change it, or take it out. In a game, a variable called "score" might start at zero. Every time the player wins a point, the score goes up by one.

A loop is a way to repeat instructions. If you want a character to take ten steps, you do not need to write "take one step" ten times. You can use a loop that says "take one step" and repeat it ten times. Loops save time and make code shorter and cleaner.

A condition is a rule that tells the program what to do in different situations. For example: "If the player's score is 100, show the message: You win!" The program checks the condition. If it is true, the action happens. If it is false, the program does something else.

### Part 4: Debugging and Becoming a Coder

Writing code is not always easy. Sometimes your program does not work the way you want it to. There might be a small mistake — a missing word, a wrong number, or a step in the wrong order. These mistakes are called bugs, and finding and fixing them is called debugging.

Debugging can be frustrating, but it is also like solving a puzzle. You read through your code line by line, looking for the mistake. When you find it and fix it, the program works — and that feeling is wonderful.

Anyone can learn to code. You do not need to be a genius. You just need patience, practice, and a willingness to make mistakes and learn from them. Many schools and websites offer free coding lessons. You can start with visual languages like Scratch, where you drag and drop blocks to build programs. Later, you can learn text-based languages like Python or JavaScript.

Coding is used everywhere — in games, apps, websites, robots, cars, and even spacecraft. The Mars rover that explores the red planet runs on code written by programmers. The app you use to chat with your friends runs on code. The world needs more coders, and you could be one of them.
